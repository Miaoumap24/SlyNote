# SlyNote

**SlyNote** is a lightweight, modern, and high-performance text editor built with Python.

---

## Installation

### Prerequisites

Ensure you have **Python 3.8+** installed on your system.

### 1. Clone or Download the Repository

```bash
git clone https://github.com/Miaoumap24/SlyNote.git
cd SlyNote

```

### 2. Install Dependencies

Install the required packages using `pip`:

```bash
pip install -r requirements.txt

```

---

## Usage

Launch SlyNote by running the main Python script:

```bash
python SlyNote.py

```

---

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + N` | Create a new document |
| `Ctrl + O` | Open an existing file |
| `Ctrl + S` | Save the active document |
| `Ctrl + Mouse Wheel` | Zoom in / Zoom out text size |
| `Ctrl + Z` | Undo last change |
| `Ctrl + Y` | Redo last change |
